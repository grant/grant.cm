# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in this project, please report it
privately rather than opening a public issue.

- Preferred: use GitHub's [private vulnerability reporting](https://github.com/grant/grant.cm/security/advisories/new).
- Alternatively, email the maintainer at granttimmerman@gmail.com.

Please include steps to reproduce and any relevant details. You can expect an
acknowledgement of your report, and we'll work with you on a fix and disclosure
timeline.
